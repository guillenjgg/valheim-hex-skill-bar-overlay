# HexSkillBarOverlay

See your skill progress as you play.

## Features

- Shows a progress bar whenever a skill gains progress.
- Displays the skill icon, current level, progress toward the next level, skill name, and amount gained.
- Multiple skill bars can be shown at the same time.
- Skill bars disappear automatically after a short delay.
- Repeated gains update the existing bar instead of creating duplicates.
- Progress track shows how far you have left until the next level.
- Optional draggable overlay.
- Overlay position is saved between game sessions.

## Dragging

Enable **Enable Dragging** in the BepInEx config.

Pause the game, then drag the overlay where you want it.

The position is saved automatically.

## Requirements

- BepInEx 5
